## How to Capture

- Power BI: Use `Win + Shift + S` to snip each visual
- VS Code: Open Explorer panel, take full screenshot
- Terminal: Run `python analytics/run_analytics.py`, screenshot output
- Neon: Login to neon.tech, screenshot the Tables view
